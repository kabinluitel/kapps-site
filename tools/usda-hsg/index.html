USDA soils with Hydrologic Soil Group filled in, for any U.S. county.

Pick a state and county and get official USDA SSURGO soil data back as ready-to-use shapefiles, with Hydrologic Soil Group (A / B / C / D) already assigned. No more pulling data by hand from Web Soil Survey.

What you get

  • Official USDA SSURGO data for any U.S. survey area.
  • Hydrologic Soil Group joined to every polygon.
  • Shapefiles that open straight in your GIS.
USDA SSURGONRCS HSG

How it works

  1. Choose the state and county or survey area.
  2. KAPPS downloads the SSURGO data and assigns the soil groups.
  3. Download the ZIP of shapefiles.

What goes in, what comes out

You provide

  • State selection dropdown
    The US state where your project is located.
  • County / Survey Area dropdown
    One or more counties. You may queue multiple counties to process together.

You get

  • Soil data package .zip
    A single ZIP containing one soil shapefile set per county you queued (named using the county FIPS code, e.g. 51013_soil.shp). Each shapefile includes component polygons with the HSG classification (A / B / C / D) already joined into the attribute table.
